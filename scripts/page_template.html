Approach

Predict once. Guide the search progressively.

ProGNet

Predicts guidance states and five start-to-goal stages from free-space points and task masks, providing an ordered representation for exploration.

ProG-RRT*

Adapts pre-solution sampling to tree progress while retaining free-space exploration. After the first solution, it combines cached guidance with informed sampling.

ProG-RRT*-Lazy

Initializes stage anchors and an auxiliary backbone, then verifies graph edges selected by optimistic path search and caches their collision-check results.

This supplement contains two physical environments, six methods, 12 planning records, and 12 main video clips. Tables compare planned length, planning time, and iterations for the individual deployments.

Experimental protocol

How to read these results

  • planned_length_m: length of the exported planned polyline, in metres.
  • planning_time_s: offline planning-call time on the Windows host, in seconds. Model loading, A* reference computation, plotting, and transfer are excluded. This is distinct from robot navigation time.
  • iterations: actual planning iterations. The internal stopping condition uses the 1.03-times grid-A* reference threshold or a limit of 10,000 iterations.
  • Map resolution: 0.05 m/cell. Planning step: 0.10 m. Nominal robot radius: 0.09 m, with a 0.02 m margin; the discrete implementation uses a three-cell inflation disk.
  • Models and planning run on the Windows host. The robot follows the exported paths using a shared tracking controller.
  • Eleven robot localization logs are available. Scene 1 lacks the NIRRT* trajectory log; its video and planning record are provided separately.
  • Each scene–method pair has one deployment record. Random configurations remain in the metadata; these demonstrations do not establish repeated-trial success rates or statistical significance.
  • Videos are supplied edits. Playback duration must not be used to infer planning or navigation time. Playback copies only change encoding; the original files are available below.
